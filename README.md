# portfolio-mireia

Portfolio personal de Mireia Killinger, diseñadora gráfica y digital.

## Estructura

- `index.html`: home (hero, sobre mí, áreas, proyectos destacados, habilidades, experiencia, formación y contacto)
- `WEBS/`, `LIFTY/`, `DISEÑO/`, `MULTIMEDIA/`: una página por área
- `assets/css/main.css`: sistema de diseño compartido (colores, tipografía, componentes)
- `assets/js/main.js`: interacciones y animaciones (preloader, cursor, scroll suave, galerías, lightbox…)
- `assets/vendor/`: GSAP, ScrollTrigger y Lenis (incluidas en local, sin depender de CDN)
- `assets/img/`: imágenes optimizadas en WebP (los originales siguen en `img/`)
- `lifty-main/`: web de Lifty

Para cambiar el color de acento, edita `--accent` en `assets/css/main.css`.
